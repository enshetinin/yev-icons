# CLAUDE.md

Personal icon set consumed by other projects (e.g. rssdeck, Next.js) via `npm i "github:enshetinin/yev-icons#vX.Y.Z"`. Usage lives in README.md; drawing and naming rules in GUIDELINES.md — follow them, don't duplicate them here.

## Workflow

- Edit only `icons/`. Never hand-edit `dist/`: it is generated by `npm run build`.
- After any change to `icons/` or `scripts/`, run `npm run build` and commit `dist/` too. Git installs and jsDelivr serve the committed build; there is no prepare step.
- The build validates icons and fails with the reason. Fix the icon, don't loosen the check in `scripts/build.mjs` unless the guidelines change.
- Versioning: patch for fixes to existing drawings, minor for new icons, major for renames or removals (they break imports like `ArrowLeftIcon` in consumer projects). Bump `package.json`, then tag `vX.Y.Z`.
- Don't commit, tag or push unless asked; the user runs those themselves.

## Conventions

- `dist/react/index.js` must stay dependency-free besides `react` and work in Server Components (no hooks, no `"use client"`).
- The catalog template `scripts/preview.html` follows the `yev-design` skill.
- The user's shell is zsh: quote any command argument containing `#` (e.g. the install spec).
